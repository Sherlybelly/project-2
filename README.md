## Project Overview

- Briefly describe the purpose of the project.
- Explain what live data set was used, and what you hope users would learn about the data set by using your project

- The purpose of our project is to show the user the picture that was of space on the date of their choice and also learn the zodiac sign associated with the date. Our project uses NASA's Astronomy Picture of the Day (APOD) API, which provides daily astronomical images along with information such as titles, dates, explanations and credits. We hope users can learn about astronomy and space by exploring NASA's collection of images. By reading the explanations on each image, we want users to learn how NASA documents different astronomical events and objects over time.

## Features

- Filtering : Our webstie uses filtering to let the user put in the date of their choice. The website fetches info from the API to find the image from the date.

- Modifying data: The website modifies data by letting the user enter a different date to get different image. The website then updates the image, zodiac sign, title, and explanation.

- Button submission: The website uses button to let the user choose their date and submit that info to get their image.
